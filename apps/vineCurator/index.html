数据库

catalog.sqlite …

固定本地 AppData（WAL 安全，不放外置盘）；本地 SQLite 为唯一真相源，离线可用。

元数据

探测只读调用 ffprobe / exiftool（video/music → ffprobe，book/comic → exiftool），JSON 落入扩展表；beets / Calibre 以只读方式打开本地库按绝对路径匹配回填，绝不写对方库。

外部工具

探测不到时可手动指定绝对路径（如 D:\tools\ffprobe.exe），保存后立即生效；留空恢复 PATH 自动探测。

备份 …

快照 = catalog.sqlite 的 VACUUM INTO 在线一致副本（含 FTS 索引），落 backups/catalog-<时间戳>.sqlite，按保留数自动清理；间隔到点由应用内定时器触发（需应用保持打开）。配置 restic 仓库后每次备份追加执行 restic backup 推送快照目录，restic 缺失/失败自动降级（本地快照不受影响）。媒体文件不进快照——restic 仓库可另行指向媒体盘。

标签 / 分类导入导出

导出分类树（物化路径）与标签词表/别名的 JSON 快照，可在不同库之间迁移；导入为增量 upsert——缺失祖先分类自动补建、同名项更新、冲突别名跳过并在结果里列出。不触碰条目关联（item_tags），只动词表与分类树。

规则自动打标

名称 优先级 状态 条件 动作 操作

条件走字段白名单（type/status/rating/year/tag/category…），值全部参数绑定不拼接；动作支持 add_tag 与 set_category（物化路径，自动补建祖先）。规则命中写 source='rule'，不会覆盖已有的人工打标/归类；扫描 / 元数据导入完成后自动运行（可取消）。

自动分类（目录结构镜像）

按每个条目父目录相对根目录的前 N 层文件夹自动建立/复用分类树并归类（如 Rock/Queen/Album/01.flac、层级 2 → 分类 Rock/Queen）。自动关联 source='auto'：重跑只更新自动关联，绝不覆盖手动/规则归类；根目录下散文件不归类。扫描完成后自动先跑本任务再跑规则。

重复检测

size 分组 → 可疑组补部分哈希（sha256：文件长度 + 头 1MiB + 尾 1MiB）→ 报告相同组；完整哈希一致的标为「已确认」。只读报告，绝不删除或修改原始媒体；需要确认时可先跑完整哈希任务。

OCR 队列 …

对 book 类 PDF 调用 OCRmyPDF（依赖 Tesseract）：识别文本写入数据库并进全文索引，派生可搜索 PDF 落派生目录 ocr/；原始文件永不修改。文件 mtime 变化自动重新识别；失败可重试。工具路径与语言（settings 键 ocr_lang，默认 eng）在设置页工具面板配置。
